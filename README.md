# Projetos Pessoais

Repositório com projetos e exercícios de programação feitos por mim, fora do contexto da faculdade.

## Projetos

### Calculadora de IMC
Programa em Java que calcula o Índice de Massa Corporal (IMC) a partir do peso e altura informados pelo usuário, classificando o resultado em: abaixo do peso, peso normal, sobrepeso ou obesidade. Permite repetir o cálculo quantas vezes o usuário quiser.

*Tecnologias:* Java

## Como executar

1. Clone o repositório
2. Abra o projeto na sua IDE de preferência (recomendado: IntelliJ IDEA)
3. Execute a classe calculadoraimc
